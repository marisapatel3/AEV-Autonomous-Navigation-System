# AEV Autonomous Navigation System
 
McMaster ELECENG 3EY4, Jan 2024 – Apr 2025.
 
Scale model autonomous electric vehicle that fuses LiDAR, inertial, and wheel odometry data to localize itself in real time, and runs both driver assist collision avoidance and fully autonomous navigation on top of that localization.
 
`Python` `C/C++` `ROS` `Linux` `MATLAB` `Simulink` `IMU` `SLAM` `Nvidia Jetson Nano` `LiDAR` `RGB-D Camera` `VESC Motor Controller`
